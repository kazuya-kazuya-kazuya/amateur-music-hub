# Amateur Music Hub

## Overview

Amateur Music Hub is an open-source platform designed for amateur musicians to share music, discover new artists, and connect with other creators.

The project aims to provide a simple and accessible community space where musicians can publish their work, receive feedback, and collaborate with others.

## Features

* User authentication
* Music sharing
* Artist profiles
* Community interaction
* Responsive web interface

## Tech Stack

### Frontend

* Next.js
* TypeScript

### Backend

* FastAPI
* Python

### Database

* PostgreSQL

### Infrastructure

* Docker
* GitHub

## Getting Started

### Clone Repository

git clone https://github.com/kazuya-kazuya-kazuya/amateur-music-hub.git

### Install Dependencies

Follow the setup instructions for frontend and backend environments.

### Run with Docker

docker compose up
